## AI Agent Project: Designed and built a multi-agentic Retrieval-Augmented Generation (RAG) system using n8n for agent orchestration, Qdrant for vector storage and semantic search, and Supabase for structured data and backend services. The system deploys four specialised AI agents in parallel, each dedicated to a distinct knowledge domain, with a central synthesiser agent that consolidates outputs into a single coherent response. This domain-separated architecture prevents cross-source data interference and hallucination, ensuring each agent retrieves and reasons only within its dedicated source of truth before synthesis. The project reflects hands-on experience in multi-agent orchestration, vector-based retrieval, and building AI systems where accuracy and source integrity are critical — directly applicable to enterprise AI agent and automation work.
